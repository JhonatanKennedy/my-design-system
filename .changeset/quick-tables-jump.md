Add a new `Table` component (`core-table` / `<Table />`). Simple, data-driven table that renders a header and body from `columns`/`rows` props, with per-column alignment, an optional caption, and an empty state. No built-in sorting/pagination — intended as the minimal building block for those to be layered on top later.
